ToneKey ⌨️✨

A beautiful, custom Android keyboard built with Jetpack Compose.

📱 About the App

ToneKey is not just another keyboard — it's a typing experience. Featuring a unique Living Sandbox background that reacts to your touch, smooth Material You aesthetics, and custom emojis.

🚀 Download

You can download the latest ready-to-install APK directly from the Releases tab.
