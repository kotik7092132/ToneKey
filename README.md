# ToneKey ⌨️✨

A custom, beautifully designed Android keyboard built with Jetpack Compose. ToneKey focuses on providing a unique, interactive typing experience with a stunning Material You aesthetic.

## 🚀 Download
You can download the latest ready-to-install APK directly from the **[Releases](https://github.com/kotik7092132/ToneKey/releases)** tab.

*(Note: Since this is a debug build, you may need to allow installation from unknown sources in your device settings.)*

## ✨ Features
* **Smart Clipboard:** Keep track of your recent copy-pastes, pin important snippets, and add quick phrases directly from the toolbar.
* **Haptic Cursor Control:** Move the cursor smoothly by swiping left or right on the spacebar, complete with subtle haptic feedback.
* **Per-Key Transparency:** Customize the opacity of every single key individually for a truly unique look.
* **Living Sandbox:** An interactive, animated background that reacts when you press keys.
* **Animation Presets:** Choose your typing experience!
  * 🍃 **Light Mode:** Optimized for performance and older devices.
  * 💥 **Heavy Mode:** Smooth spring animations and glow effects for powerful devices.
* **AMOLED Theme:** Pure black mode for OLED screens to save battery.
* **English & Russian Localization:** The entire app interface is fully translated.
* **Material You Design:** Beautiful color palettes and smooth, pill-shaped keys.
* **Modern Typography:** Carefully selected fonts for a clean and stylish look.

## 🛠 Built on Mobile
This project was fully compiled and packaged into an APK directly on an Android device using **Termux**. No PC was used during the initial build process!
